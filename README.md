# ⚽ الهبدة المرتدة — El-Habda El-Mortadda

لعبة أسئلة Multiplayer بالعربي (لهجة مصرية) — كل لاعب على موبايله، والحكم على موبايله، بدون سيرفر (PeerJS / WebRTC).

## التشغيل
- **أونلاين:** افتح الرابط من GitHub Pages.
- **محلي:** `npx serve .` أو أي سيرفر static (لازم http مش file://).

## طريقة اللعب
1. الحكم يدوس "إنشاء غرفة" ويظهرله كود 4 حروف + QR.
2. كل لاعب يفتح نفس الرابط، يكتب الكود واسمه ويختار لون.
3. الحكم يبدأ الماتش ويتحكم: صح/غلط/إظهار الإجابة/VAR/كروت/تراجع.

## القواعد
- إجابة صح: +1 (قابلة للتعديل) · هبدة مرتدة (بعد غلط حد تاني): +2
- 🟨 -1 · 🟥 -3 · أصفرين = أحمر + إيقاف سؤال
- آخر 3 أسئلة = ⏱ وقت بدل ضائع (نقاط مضاعفة)
- Power-ups: ©️ كابتن ×2 · 🧊 تثبيت خصم 3 ثواني

## الصور
حط الصور في `questions_images/` حسب المسار المكتوب في السؤال (`players/p001.jpg`...). لو الصورة مش موجودة يظهر placeholder.

## 🎮 العب دلوقتي (استضافة مجانية)
https://seif92498.github.io/el-habda-el-mortadda/

الحكم يفتح الرابط ويضغط «اعمل غرفة»، وبعدين يبعت الرابط اللي بيطلع في خانة الدعوة (`?room=XXXX`) للـ 4 لاعبين.
## الأسئلة
عدّل من شاشة "📝 إدارة الأسئلة" (إضافة/تعديل/حذف/رفع JSON) — بتتحفظ في المتصفح.
